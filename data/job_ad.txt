Junior Software Engineering Trainee
Helsinki, Finland (Hybrid)

We are looking for a junior software engineering trainee to join our platform
development team. In this role, you will help build and test backend and
systems-level tools used by engineering teams.

Responsibilities
- Develop small features and internal tools using Python and C/C++.
- Work in a Linux/Unix development environment.
- Debug software issues using logs, GDB, Valgrind, and careful problem solving.
- Write manual tests and simple regression tests to improve software quality.
- Use Git and GitHub for version control and code review.
- Document your work clearly and communicate progress with the team.
- Explore AI tools such as ChatGPT or GitHub Copilot to support learning,
  debugging, and documentation.
- Help with API integration and JSON parsing for internal automation workflows.

Required skills
- Basic Python programming.
- Basic C/C++ programming.
- Linux or Unix command-line experience.
- Git and GitHub.
- Testing, debugging, and troubleshooting.
- Communication, teamwork, and willingness to learn.

Nice to have
- Docker.
- REST API experience.
- Web scraping or automation experience.
- Machine learning or AI interest.
